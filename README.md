# Matrix Playground

An interactive **Streamlit web app** designed to help students and professionals explore **linear algebra concepts** with ease.  
It supports matrix construction, symbolic calculus, eigen-analysis, and visualization — all in one place.

---

##  Features
- **Matrix Construction**
  - Build matrices manually or auto-generate random ones (singular/non-singular).
  - Save and update matrices dynamically.

- **Operations & Calculus**
  - Perform arithmetic: addition, subtraction, multiplication.
  - Compute matrix inverses.
  - Symbolic differentiation and integration with respect to `x`.

- **Eigen-Analysis**
  - Compute eigenvalues, eigenvectors, and multiplicities.
  - Display results in a structured, readable format.

- **Visualization**
  - Plotly integration for interactive matrix visualizations (extendable).
